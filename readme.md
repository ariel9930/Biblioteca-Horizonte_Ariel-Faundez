# Biblioteca Horizonte

**Biblioteca Horizonte** es una plataforma web interactiva orientada al descubrimiento y selección de libros. El proyecto está diseñado con una interfaz moderna e intuitiva que permite a los usuarios explorar diversas categorías literarias, ver recomendaciones destacadas y gestionar una selección de libros en tiempo real.

---

##  Características Principales

* **Autenticación Básica:** Formulario de inicio de sesión/ingreso rápido mediante correo electrónico en la barra de navegación.
* **Navegación por Categorías:** Clasificación visual de libros por temas (Novelas, Ciencia, Historia, Tecnología, Arte e Infantil).
* **Sección Multimedia:** Integración de video promocional/destacado para la plataforma.
* **Catálogo de Recomendaciones:** Muestra de obras destacadas con información sobre el título, autor y acceso a más detalles.
* **Contador de Selección:** Sistema interactivo para agregar libros a una lista o carrito de selección.

---

##  Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos personalizados (`static/css/style.css`) con diseño adaptativo.
* **JavaScript:** Lógica de interacción y manipulación del DOM (`static/js/script.js`).
